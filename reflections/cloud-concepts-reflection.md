## Cloud Concepts Reflection
Cloud computing is a technology that I use in my daily life. Some cloud services that I regularly use are Google Drive, Messenger, and Canva. Google Drive helps me store my school files, documents, and projects online. I can open my files using different devices as long as I have an internet connection. Messenger helps me communicate with my classmates, friends, and family. Canva helps me create designs, presentations, and other school activities in an easier way.

The service model of these applications is Software as a Service (SaaS) because users can directly use these applications through the internet without needing to install or manage the system. Their deployment model is Public Cloud because these services are available to many users around the world. These companies provide their services online, and users can access them anytime using an account and an internet connection.

Git and GitHub are also important tools when working with cloud-based projects. Version control helps developers save, organize, and track changes in their projects. It allows them to view previous versions of files and recover changes when mistakes happen. This is very useful because many cloud projects require teamwork and collaboration.

GitHub helps team members work together by allowing them to upload, share, and update files in one place. It also shows the changes made by each member and the time when those changes were done. This helps prevent confusion and reduces errors because team members can review updates before using them.

After learning about cloud concepts, I realized that cloud computing makes tasks easier, faster, and more convenient. Many applications that I use every day depend on cloud technology. As a BSIT student, learning about cloud computing, Git, and GitHub helps me improve my technical skills and prepares me for future IT projects.
