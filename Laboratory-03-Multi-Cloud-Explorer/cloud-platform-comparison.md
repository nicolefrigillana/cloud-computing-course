## — Analysis Questions —

**Which cloud provider offers the broadest range of services?**
AWS offers the widest catalog with over 200 services spanning every category. Its decade-long lead and massive customer base drive unmatched depth and maturity across every workload category.

**Which provider best integrates with Microsoft technologies?**
Azure provides native, seamless integration with Windows Server, Active Directory, Microsoft 365, .NET, and SQL Server. Organizations already invested in the Microsoft stack can migrate with minimal rework and preserve existing identities.

**Which provider is strongest in Artificial Intelligence and Kubernetes?**
GCP leads in both areas. Google created Kubernetes, and GKE remains the most advanced managed container platform. GCP also excels in AI through Vertex AI, TensorFlow compatibility, and custom Tensor Processing Units designed specifically for machine learning.

**Which cloud platform would you personally choose and why?**
I would choose AWS for most general purposes because its unmatched service breadth and global footprint mean it can support almost any workload today and as it grows. However, for AI-first or data-analytics products, I would select GCP, and for any organization already on Microsoft tools, Azure is the clear practical choice.
